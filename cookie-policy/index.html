Cookie policy

Last updated 3 November 2026

Acrostia sets no tracking, advertising or analytics cookies. None.

The one thing stored

When you close the privacy notice at the bottom of the page, your choice is saved in your browser's local storage under the key acrostia-consent. This is not a cookie, it is not sent to any server, and no other site can read it. It contains one short text value and nothing else.

Requests other sites see

  • Google Fonts serves the typefaces, so your browser requests font files from fonts.googleapis.com.
  • Unsplash and Pexels serve the example photos from their CDNs.

Those providers see your IP address, browser type and which page requested the file, which is true of every image and font on the web. We add no identifiers to these requests.

Birthday tools keep one entry per tab

The birthday tools (birthday profile, zodiac, birthstone and the others in that family) save the birth date and name you type into your browser's session storage under the key acrostia-bd-context-v1. This saves you retyping the same date on each birthday page in the same browser tab. It is never sent to any server, and it disappears completely when you close the tab.

Sharing a birthday profile is always an explicit action: nothing about you is ever added to a web address on its own. If you press "Create share link", the page builds a link that carries the name and birth date you entered, and the page tells you plainly that the link contains those details before you copy or send it anywhere.

Clearing the stored value

In your browser: Settings, Privacy, Site data, find this site, and clear it. The privacy notice will simply appear again next visit.
